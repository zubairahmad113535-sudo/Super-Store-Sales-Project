# Superstore Sales & Profit Analysis

## Project Overview
This project analyzes the Superstore sales dataset using Python, Pandas, Matplotlib, and Seaborn to understand business performance and identify important sales and profit patterns.

## Business Questions
The analysis focuses on:
- Which category generates the highest sales and profit?
- Which products generate the highest sales?
- Which products are causing the biggest losses?
- Which region generates the highest sales and profit?
- Which customer segment contributes the most sales and profit?
- How does discount relate to profit?
- How do sales change over time?

## Dataset
The dataset contains **9,994 rows and 21 columns**, including information about orders, customers, products, sales, quantity, discount, profit, shipping mode, and region.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings
- **Technology** generated the highest sales: **$836,154.03**
- **Technology** generated the highest profit: **$145,454.95**
- The **West** region generated the highest sales: **$725,457.82**
- The **West** region generated the highest profit: **$108,418.45**
- The **Consumer** segment generated the highest sales and profit.
- Total sales were **$2,297,200.86**
- Total profit was **$286,397.02**
- Total quantity sold was **37,873**
- Discount and profit showed a negative correlation of approximately **-0.22**

## Analysis Performed
The project includes:
- Data loading and exploration
- Date type conversion
- Sales and profit analysis
- Category and sub-category analysis
- Product performance analysis
- Regional analysis
- Customer segment analysis
- Discount and profit correlation
- Data visualization

## Project Goal
The main goal of this project is to use Python-based data analysis to understand the factors associated with business performance and generate insights that can support better business decisions.
